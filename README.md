# Andrieli Guisso Fotografia

Portfólio fotográfico responsivo com identidade editorial, galeria filtrável e animações suaves.

## Páginas

- `index.html` — apresentação, trabalhos em destaque e experiências
- `portfolio.html` — galeria com filtros e visualização ampliada
- `sobre.html` — posicionamento, valores e processo de trabalho
- `agendamento.html` — contato direto pelo WhatsApp e dúvidas frequentes

As fotografias originais permanecem apenas no projeto local e não são enviadas ao Git. As versões otimizadas para carregamento no navegador ficam em `img/web`.

## Como visualizar

Abra `index.html` no navegador. O projeto usa apenas HTML, CSS e JavaScript, sem etapa de build.

O contato do site direciona para o WhatsApp da fotógrafa com uma mensagem inicial pronta.
